# Qenna Cover Creator

Standalone cover design tool bundled with
[Qenna Writer](https://github.com/Pedrovskigg/qenna-writer).

## Fonts

All cover fonts ship with the app (`public/fonts/`), so it works offline.
They are copied from the Qenna Writer repository with
`npm run fonts:sync`, which also regenerates `public/fonts/fonts.css`.
Run it again whenever `src/data/fonts.js` changes. Each font keeps its
SIL Open Font License file in its own folder.
